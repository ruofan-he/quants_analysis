## 目的
株式市場でヒストリカルな価格と取引ボリュームからなんらかの取引に有用な情報を取り出したい。

## モデリング
市場参加者をA,B,C...とする。各参加者が$`t`$時点で保有するアセット数を$`S_A(t),S_B(t),S_C(t)...`$とする。
各時点での価格を$`P(t)`$とする。
各時点での取引ボリュームを$`V(t)`$とする。
現時点を$`T`$とする。
Aの視点で過去$`t`$に行った取引を見てみよう。
そうすると取引に使った費用および現時点$`T`$からみたその取引由来のPLが表現できる。
```math
\text{transaction} : \qquad P(t) \times [ S(t) - S(t-1) ]\\
\text{transaction PL} : \qquad [P(T) - P(t)] \times [S(t) - S(t-1)]
```
ネットの取引残高とネットのPLも以下のように表現できる。
```math
\text{net Amount} : \qquad 
S(T) = S(0) + \sum_{t=1}^{T} [S(t) - S(t-1)]\\

\text{net worth} : \qquad
P(T)S(T)\\

\text{net transaction} : \qquad
\sum_{t=1}^{T} P(t) \times [S(t) - S(t-1)]\\

\text{net transaction PL} : \qquad
\sum_{t=1}^{T} [P(T) - P(t)] \times [S(t) - S(t-1)]\\
= P(T)S(T) -P(T)S(0) - \sum_{t=1}^{T} P(t) \times [S(t) - S(t-1)]
```
これら市場参加者各々から見た取引を集約して取引ボリュームは次のように表現できる。
```math
V(t) = \frac{1}{2} |S_A(t) - S_A(t)| + \frac{1}{2}|S_B(t) - S_B(t)| + ... \\
V(t) = \frac{1}{2} \sum_{n}| S_n(t) - S_n(t-1) |
```
上記のように取引は売り手買い手両者の保有数変化の絶対値で重複しているのでダブルカウントを排除した上で総和される値である。$`t`$時点での取引に対してAから見たPLは$`[P(T) - P(t)]\times[S_A(t) - S_A(t-1)]`$として明確に表せるのだが、市場参加者全体のPLの総和は0とならざるを負えない。なぜなら市場に存在する株数は保存するためである。
```math
\text{total transaction PL} : \qquad
0 = [P(T) - P(t)] \sum_n S_n(t) - S_n(t-1) \\

\text{total Amount} : \qquad
M = \sum_n S_n(t)
```
ヒストリカルな株価とその取引ボリュームから次の情報を読み取ることができるか？
- 市場参加者の損益分布
- 市場参加者の保有数の分布

一般的にはそれらを読み取ることは難しいと考える。
誰かにとっての儲け額は他人にとって同額の損であるが、取引ボリュームを見るだけでは誰が儲けたポジションを持っているかの情報は失われてしまう。
ただし時価で益となっている場合になっている場合には、その取引をアンワインドする圧力が働くために、
基本的には過去にどのような価格帯で取引が行われたかの情報を取り出すこと自体は有用である。

## 誰かの得は誰かの損指標
価格時系列$`P(t)`$と取引ボリューム時系列$`V(t)`$を使って次のような時系列を作ってみる。$`t=0`$から$`t=T`$まで過去の取引に基づく誰かの得=誰かの損の時系列である。これらの特徴を取り出したい。
```math
\text{取引資金移転量} : \qquad P(t)V(t)\\
\text{取引による誰かの得=損} : \qquad [P(T) - P(t)]V(t)
```
グラフのアイデアとして
- 横軸単位=$`P`$ 縦軸単位=$`V`$としてヒストリカル$`V(t),P(t)`$のバーチャート
- 横軸単位=$`P`$ 縦軸単位=$`V`$としてヒストリカル$`V(t),P(T)-P(t)`$のバーチャート
- 横軸単位=$`T`$ 縦軸単位=$`P`$ Z軸単位=$`V`$としてヒストリカル$`V(t),P(t)`$のバーチャート
- 横軸単位=$`T`$ 縦軸単位=$`P`$ Z軸単位=$`V`$としてヒストリカル$`V(t),P(T)-P(t)`$のバーチャート
- また過去ほど取引量が持つ情報は無くなってくるので、ボリュームをなんらかの手法でディケイさせたもの
